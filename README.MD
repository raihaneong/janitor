# Janitor

Janitor is a command-line utility collection.

## Install

Requires Node.js 22 or newer (works on Windows, macOS, and Linux).

```sh
npm install -g git+https://github.com/raihaneong/janitor.git
```

Install a specific version by pinning a tag:

```sh
npm install -g git+https://github.com/raihaneong/janitor.git#v1.0.0
```

To update, re-run the install command — npm replaces the old version.

On Windows, npm generates `janitor.cmd` and `janitor.ps1` shims automatically, so `janitor` is available in any terminal (cmd, PowerShell, Git Bash) after installing.

## Clock

Run the live clock with:

```sh
janitor clock
```
